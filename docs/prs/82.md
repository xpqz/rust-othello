# Issue 82: Implement iterative deepening with root-only previous best

## RED

Issue: #82 — Implement iterative deepening with root-only previous best.

Tests added in `tests/search.rs`:

- `id_matches_depth`: for the start position, the double-no-move parent, and
  the pass fixture, `search_iterative(board, d)` matches `search(board, d)`'s
  score at depths 1-4, reports `Complete`, depth `d`, `solved = false`, and
  its best move achieves the returned score.
- `id_root_ordering`: at depth 4 from the start, the total nodes used by
  iterative deepening are fewer than the sum of four independent fixed-depth
  searches, while the score matches the direct depth-4 result.
- `id_zero_is_fallback`: depth 0 returns the first legal move, the static
  evaluation, depth 0, and `Fallback`.

Expected failure:

```text
error[E0432]: unresolved import `othello::search::search_iterative`
```

The failure is intended: the function does not exist yet.

## Intended behaviour

- `search_iterative(board, max_depth, config)` deepens from 1 to `max_depth`,
  keeping the previous iteration's best move and trying it first at the root.
  Interior node ordering is unchanged.
- Each completed depth replaces the result; the final result is the last
  completed depth. Depth 0 is the same deterministic fallback as `search`.
- `nodes` is the total across all completed iterations.
- A root first-move order that starts with the previous best reduces the total
  below the sum of independent fixed-depth searches.
- Deadlines, partial iterations, and solver early-stop are #83; this issue
  only adds deepening and root ordering.
