Issue: #67 — Implement flips, play, pass, terminal, and WTHOR score.

Tests added in `tests/movegen.rs`:

- `start_flips`: pins the flipped discs for each legal opening move.
- `play_start`: pins the swapped board after `c4`.
- `counts_start`: checks disc and empty counts before and after a move.
- `pass_swaps`: checks that a pass swaps the side-relative board.
- `terminal_board`: checks terminal detection, a tied terminal with empties
  scoring zero, and a winner receiving the empties.

`tests/score.rs` gains `terminal_wiring`, which checks
`terminal_score(final_score(board))` on a terminal win.

Expected failure:

```text
error[E0432]: unresolved imports `othello::board::disc_count`,
`othello::board::empty_count`, `othello::board::final_score`,
`othello::board::flips`, `othello::board::is_terminal`,
```

The failure is intended: those functions do not exist yet.

## Intended behaviour

- `flips(board, sq) -> u64` returns the opponent discs flipped by a legal move.
- `play(board, sq) -> Board` applies the move and returns the swapped board.
- `pass(board) -> Board` swaps the side-relative board.
- `is_terminal(board) -> bool` is true when neither side has a move.
- `disc_count(bits) -> u32` and `empty_count(board) -> u32`.
- `final_score(board) -> i32` is the side-to-move-relative WTHOR score; the
  winner receives empty squares and a tied terminal with empties scores zero.
- `terminal_score(final_score(board))` remains the only centidisc conversion.
