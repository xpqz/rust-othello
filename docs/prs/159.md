# Issue 159: Route Rust build artefacts to Space2 when mounted

Setup work, with no test stage.

## Change

- **`scripts/cargo-target.sh`** (new) prints
  `/Volumes/Space2/othello/<checkout>/target` when the volume is really
  mounted: its device id differs from `/`, so a stale `/Volumes/Space2`
  directory on the system disk does not count. Otherwise it prints nothing.
  `OTHELLO_CARGO_VOLUME` overrides the mount point. Modelled on ghost's
  `scripts/cargo-target.sh` and nars's `scripts/lib/cargo-target.sh`.
- **One target per checkout:** the root, `gui`, `tools` and `trainer`
  crates of a checkout share that directory, so the engine is compiled once
  for all of them. Separate checkouts get separate directories, so a run
  worktree's binaries are never overwritten by builds elsewhere.
- **Scripts:** the hard-coded `tools/target/...` paths in
  `tools/tests/{edax_depth,edax_phase,edax_resume,probcut_fit,probcut_screen,solve_times,version_match}.sh`
  and `scripts/version_workers.sh` now use
  `${CARGO_TARGET_DIR:-<the old path>}`, so they work routed or not.
- **Outside the repo:** a block appended to `~/.zshenv`, guarded on `$PWD`
  being inside `/Users/stefan/work/crust/othello*`, exports
  `CARGO_TARGET_DIR` from the checkout's own `scripts/cargo-target.sh` when
  it prints a path. Checkouts without the script (the pinned
  `othello-book-ext` and `othello-book-run` worktrees) keep their local
  targets.

## Commands and results

- Routing, each from a fresh `zsh -c`: main checkout and `trainer/` →
  `/Volumes/Space2/othello/othello/target`; `othello-book-ext` → unset;
  nars → its own `/Volumes/Space2/skalpel/target-shared` (unchanged);
  `/tmp` → unset. `OTHELLO_CARGO_VOLUME=/nonexistent` and a same-device
  directory both print nothing.
- `scripts/check.sh` with `CARGO_TARGET_DIR=/Volumes/Space2/othello/othello/target`:
  exit 0, 6 min 20 s (cold build on the volume).
- `tools/tests/probcut_screen.sh` and `tools/tests/version_match.sh`,
  routed: exit 0. The other five tool scripts need Edax or long runs and
  were not re-run; their change is the same substitution.
