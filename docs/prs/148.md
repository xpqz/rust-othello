## Step 2: runtime replay (`docs/tuning/probcut2_replay.log`)

New subcommand `probcut_fit replay --in FILE --dev FILE`: the audit fold
(same folds, deduplication and development exclusion as `fit`), positions
with 21–56 empties, every depth 4–14 the position has a value for; per
position and depth one high query (`probcut(board, d, v_d, v_d + 1)`,
false only on a top-level return of `v_d + 1`) and one low query
(`(v_d − 1, v_d)`, false only on `v_d − 1`), with `ProbCut::FITTED` at
each candidate margin and a cleared table per query. Run at `fd3f1cf` (the
log's first lines give commit and binary SHA-256), single-threaded beside
the tuning match. Reported, not gated.
