## Review response: final tuning review of `4981251`

### The match driver now voids fresh pairs too

`tools/src/main.rs` `match_command`: the load rule was applied only to
pairs read back from a journal, so a fresh run counted pairs played above
`--max-load` in its summary. Now one loop treats saved and fresh pairs
alike: every pair without two valid games under the load rule (missing,
half-played, or above the limit under time control) is removed from the
results and the journal and played again, up to ten passes; if pairs are
still void after that, the run exits with an error and prints no summary.
`load_average` reads `OTHELLO_TOOLS_LOAD` first, so tests fix the
measured load. Tools 1,298 production lines.

- New `tools/tests/journal.rs` `fresh_overload_void`: at load 9 with
  `--max-load 7`, a timed match fails after ten void passes, prints no
  summary and keeps no record; the same command at load 1 then completes
  four valid records, `report` accepts the journal, and it equals a run at
  load 1 throughout.
- `tools/tests/baselines.rs`: its `tools` helper fixes the load at 0; three
  of its timed-match tests (`timed_and_node_agents`, `classic_agent`,
  `timed_default_max_load_is_jobs_plus_two`) failed under real machine load
  once fresh pairs could be voided.
