# Issue 94: Fix mobility scaling and frontier antisymmetry

## RED

Tests added in `tests/eval.rs`:

- `mobility_unequal_counts`: a one-move board with unequal legal-move counts
  has nonzero mobility and the correct sign.
- `mobility_formula`: pins `(mine - theirs) * 1000 / (mine + theirs + 1)`.
- `frontier_swap`: start is zero; across seeded playouts,
  `frontier(board) == -frontier(pass(board))`.

Expected failure:

```text
error[E0432]: no `mobility` in `eval`
```

## Intended behaviour

- `mobility(board)` returns the scaled signed mobility with
  `MOBILITY_SCALE = 1000`, so unequal counts never round to zero.
- `frontier(board)` returns `opp_frontier - own_frontier`, where a frontier
  disc is adjacent to an empty square.
- `evaluate` is unchanged in this issue; the phase-weighted combination is
  #96.
