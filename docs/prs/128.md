# Issue 128: Mobility overlays: opponent move counts and frontier discs

## RED

Tests first; the GUI has no `othello_gui` library or `overlays` module.

New `gui/tests/overlays.rs` covers the two pure computations:

- `start_move_counts`: each of Black's four start moves leaves White three
  legal moves; non-move squares carry `NO_MOVE`.
- `forced_pass_is_zero`: the hand-built position
  `e2e363232cd80009 / 081c18dcd227ff00`, move 47, leaves the opponent with
  no legal move while the other side still has moves. The count is 0.
- `start_frontier`: all four discs on the start board touch an empty
  square.
- `surrounded_disc_is_not_frontier`: a centre disc with all eight
  neighbours occupied is excluded, while the surrounding discs remain
  frontier.
- `white_to_move_is_relative`: a White-to-move position (after Black c4)
  gets counts for the side to move, and `frontier` is unchanged by
  swapping `me` and `opp`.

Expected failure:

```text
error[E0433]: cannot find module or crate `othello_gui` in this scope
 --> tests/overlays.rs:2:5
```

### Intended design

- `gui/src/lib.rs` exposes `pub mod overlays`.
- `gui/src/overlays.rs`:
  - `NO_MOVE = 255`.
  - `opponent_move_counts(board) -> [u8; 64]`: for each legal move of
    `me`, the number of legal moves for the opponent after `play`; 0 means
    the opponent would pass; `NO_MOVE` on non-move squares.
  - `frontier(board) -> u64`: all occupied discs that touch at least one
    empty square in the eight directions. The GUI intersects this with the
    human's discs for the overlay; the pure function covers both colours.
- The side panel gets two session-persistent toggles, both off by default:
  opponent move count and frontier discs. They draw only on the human's
  turn and never affect engine choice or search.
- The count overlay marks a 0 (forced pass) distinctly, and neither
  overlay hides the last-move marker.
- `scripts/check.sh` gains the GUI fmt, clippy and test commands.
- `gui/README.md` describes both overlays and the rule of thumb: prefer
  moves that leave you few discs touching empty squares.

No engine, tools or trainer changes are intended.
