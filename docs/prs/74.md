## Intended behaviour

- `Agent` has `choose(&mut self, board) -> Option<u8>` and a default no-op
  `reset()`. Constructors return named structs, so tools can store them and
  call `reset` between games.
- `RandomAgent` keeps its seed and a `Rng`; `reset` reseeds it.
- `greedy_agent()` maximises `disc_count` of the mover after the move and keeps
  the lowest square on ties, making it deterministic and matching DESIGN's
  disc-greedy baseline.
- `search_agent(config, limits)` returns `None` without calling `search` when
  the side to move has no placement; otherwise it runs fixed-depth search and
  returns `best`.
- `SearchLimits { max_depth }` is the Phase 2 limit. Time and node limits are
  #83.
- `common::agent_game(start, first, second)` is the shared per-game runner: it
  toggles agents every ply, passes when the side to move has none, and stops
  at a terminal board.
