## Intended behaviour

- `Agent` has one method, `choose(&mut self, board) -> Option<u8>`. A blanket
  impl adapts any `FnMut(Board) -> Option<u8>`, so constructors return small
  closures and each call creates fresh state.
- `random_agent(seed)` picks a uniformly chosen legal move from its `Rng`.
- `greedy_agent()` maximises `-evaluate(play(board, sq))` and keeps the lowest
  square on ties, making it deterministic.
- `search_agent(config, limits)` returns `None` without calling `search` when
  the side to move has no placement; otherwise it runs fixed-depth search and
  returns `best`.
- `SearchLimits { max_depth }` is the Phase 2 limit. Time and node limits are
  #83.
- `common::agent_game` is the shared per-game runner: it toggles agents every
  ply, passes when the side to move has none, and stops at a terminal board.
