## RED

Issue: #84 — Add time controls, bench, and equal-node agent naming.

Tests added:

- `tests/cli.rs::bench_time_controls`: `bench --depth 10 --time-ms 0` and
  `bench --depth 10 --max-nodes 1` both succeed, report depth 0, and print
  `nps`.
- `tools/tests/baselines.rs::timed_and_node_agents`: `ab:2:1000` reports
  `evaluate, depth 2, time 1000`, and `phase2:1000` reports
  `eval_phase2, depth 4, time 1000`.
- `tools/tests/baselines.rs::node_limited_match`: `--nodes 100` runs
  reproducibly, reports `nodes 100`, and is byte-identical on repeat.

Expected failure: the current CLI rejects `--time-ms`/`--max-nodes`, bench
prints no `nps`, the tools reject `ab:2:1000`/`phase2:1000`, and `--nodes` is
an unknown option. The failures are intended.

## Intended behaviour

- `bench` parses `--depth`, `--time-ms`, and `--max-nodes`, searches the start
  position with `search_limited`, and prints depth, score, nodes, nps, and
  elapsed milliseconds.
- Tool agent names accept `ab:<depth>[:<time-ms>]` and
  `phase2[:<time-ms>]`. A time suffix sets the deadline; `ab:<depth>` and
  `phase2` stay unlimited.
- `match --nodes N` sets a node budget for search agents, making equal-node
  matches deterministic.
- `#85` owns the broader deadline/CLI/tools test matrix; this issue adds the
  controls plus the minimal RED checks.
