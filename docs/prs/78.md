# Issue 78: Implement pair-bootstrap intervals, Elo, and reporting

## RED

Issue: #78 — Implement pair-bootstrap intervals, Elo, and reporting.

Tests added in `tools/tests/stats.rs`:

- `elo_points`: `elo_from_score` gives 0 at 0.5, `±400·log10(3)` at
  0.75/0.25, and infinity at 0/1.
- `bootstrap_deterministic`: the same 12 mixed pair scores and seed produce an
  identical `Bootstrap` interval; the interval contains the mean and stays in
  `[0, 1]`.
- `degeneracy`: zero pairs are `Insufficient`; one pair is `Uninformative`
  with the clipped `[0, 1]` bound; 20 tied pairs and 15 all-wins pairs are
  `Uninformative` rather than strong claims.
- `report_counts`: three pair scores report 3 pairs, 6 games, 1/1/1 W/D/L,
  mean 0.5, an uninformative interval, and no Elo interval.
- `elo_range`: insufficient and unbounded endpoint intervals have no Elo
  range; a finite bounded interval maps each endpoint through
  `elo_from_score`.

Expected failure:

```text
error[E0432]: unresolved imports `othello_tools::harness::Interval`,
`bootstrap_ci`, `elo_from_score`, and `report`
```

The failure is intended.

## Intended behaviour

- `Interval` has `Insufficient`, `Uninformative { mean, low, high }`, and
  `Bootstrap { mean, low, high }`; only `Bootstrap` is informative.
- `bootstrap_ci` uses the engine `Rng` for deterministic percentile
  resampling when there are at least 10 pairs and non-zero variance.
  Otherwise it uses the Hoeffding bounded-mean half-width
  `sqrt(ln(40) / 2n)` and clips to `[0, 1]`; zero pairs are insufficient.
- `elo_from_score(score) = 400 · log10(score / (1 - score))`. Elo endpoints
  exist only for finite bounds strictly inside `(0, 1)`.
- `report` returns pairs, games (two per pair), pair-level W/D/L, mean,
  interval, and the optional Elo range.
