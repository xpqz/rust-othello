## Intended behaviour

- `Interval` has `Insufficient`, `Uninformative { mean, low, high }`, and
  `Bootstrap { mean, low, high }`; only `Bootstrap` is informative.
- `bootstrap_ci` uses the engine `Rng` for deterministic percentile
  resampling when there are at least 10 pairs and non-zero variance.
  Otherwise it uses the Hoeffding bounded-mean half-width
  `sqrt(ln(40) / 2n)` and clips to `[0, 1]`; zero pairs are insufficient.
- `elo_from_score(score) = 400 · log10(score / (1 - score))`. Elo endpoints
  exist only for finite bounds strictly inside `(0, 1)`.
- `report` returns pairs, games (two per pair), pair-level W/D/L, mean,
  interval, and the optional Elo range.

## Review responses

- Moved the statistics to `tools/src/stats.rs` (PLAN's layout) and updated
  #78's Files to `tools/src/stats.rs, tools/tests/stats.rs`.
- `report` now takes per-game points per pair, `&[(f64, f64)]`, derives the
  pair means, and counts true game W/D/L. The fixture covers 0.75 and 0.25
  pairs: `(1.0, 0.5)`, `(0.0, 0.5)`, and `(0.5, 0.5)`.
- `bootstrap_deterministic` now also checks that the bootstrap width is
  narrower than the Hoeffding width for the same pair count.
- The percentile rule is stated in the notes: the 2.5% and 97.5% order
  statistics of the sorted resample means, at index
  `round((len - 1) * p)`.
- `report` uses the 10,000-resample default; `report_with` exposes the
  resample count and seed for tests.
