## Intended behaviour

`src/board.rs` exposes:

- `Board { me: u64, opp: u64 }` with `Copy` and `Eq`;
- `Board::start()` for the black-to-move start position, with black on d5/e4
  and white on d4/e5;
- `Dir` with E/W/N/S/NE/NW/SE/SW;
- `shift(bits, dir)` using the `NOT_A`/`NOT_H` masks;
- `legal_moves(me, opp)` returning the landing empties.

Random-position differential coverage and perft belong to #70/#71.

## Review responses

- `start_board` now builds the expected position from coordinates
  (`bit(3,4)|bit(4,3)` and `bit(3,3)|bit(4,4)`) rather than copying the
  production constants. The copy is used after copying, so it still exercises
  `Copy`.
- Added hand fixtures for the six-step run limit, all four diagonals, the
  `NOT_A` wrap guard, an occupied landing, and a gap in the run.
- Added a positive north shift and full-board mask counts: 56 for orthogonal
  directions and 49 for diagonals.
- The start position is now `Board::START`, a constant, and `Board` will derive
  `Debug` alongside `Clone`, `Copy`, `PartialEq`, and `Eq`.
