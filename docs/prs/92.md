# Issue 92: Endgame oracle and preloaded-TT tests

## Notes

This is a tests-only issue: no production behaviour changed, so there is no
intended RED failure. The existing solver/WDL implementation already passes
the new tests.

Tests in `tests/search.rs`:

- `solve_sample_deep`: the documented seeded sample (seed `0x5A3A11`, 1,000
  positions at 6–10 empties) against the independent test minimax. It is now
  `#[ignore = "release-only"]`, so the heavy run is
  `cargo test --release --test search -- --ignored`.
- `solver_known_endgames`: two corpus endgames (12 and 11 empties) with
  expected exact scores `-2200` and `1800`, checked against both the solver
  and the independent test minimax. Release-only.
- `solver_reuses_endgame_bounds`: runs WDL with a table, then exact solve with
  the same table, and checks the exact score on ten seeded 6–8-empty
  positions.
- Existing coverage already includes terminal/pass, heuristic-preloaded TT
  rejection, endgame-entry rejection by heuristic search, and interior
  heuristic nodes below the threshold.

The known positions are reference-verified against the test minimax, not
claimed as a hand proof, and this does not claim exhaustive coverage of all
positions at or below 8 empties.

## Review response

- `solver_reuses_endgame_bounds` now sums exact-solve nodes over the ten
  positions for a cold context and for a WDL-warmed table. It still checks
  every score, and additionally asserts `warm_nodes < cold_nodes`, so the
  test fails if endgame bounds are ignored.
