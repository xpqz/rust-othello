# Issue 166: Tools clock variant grammar

Tools side of `docs/design/time.md` amendment 1 (approved). This branch
starts from #165's GREEN commit, since it needs `ClockPolicy::variant`
and `allot_with`. It merges after #165.

## RED

- **Stub:** `agents::policy(name) -> Result<usize, String>` always
  returns `Ok(0)`. `time_field` still refuses a `v` suffix.
- **Tests,** in `tools/tests/clock.rs` (2, both failing against the stub):

  | Test | Checks |
  |---|---|
  | `variant_grammar` | `pc:80:c13000v2`, `…v0`, `…v3+book`, `ab:2:c50v1` and plain `pc:80:c13000` give the clock and variants 2, 0, 3, 1 and 0; a name without a clock is variant 0; `v4`, `v`, `vx`, `pc:80:3000v1` (a `v` without a clock) and `pc:80:cv1` (no ms) are refused |
  | `variant_wiring` | `search` of `pc:80:c50000v2`, `…v3` and plain `pc:80:c50000`, after `clock(40 s)`, reports the start, deadline and exits of `allot_with` under variants 2, 3 and 0 |

- **Results:** the tools suite has 2 failures, both these tests; the
  rest pass. Clippy is clean, and tools are at 1,483 of 1,500 lines.

### GREEN plan

- `time_field` splits a `c` field at `v`: the ms must lie in
  1..=`MAX_CLOCK_MS` and k in 0..=3 (`ClockPolicy::variant(k)` exists).
- `policy(name)` returns k, or 0 without a `v`.
- `search` builds `clock_agent` with `ClockPolicy::variant(policy(name)?)`.

## RED review response

- **Negative names agree across every public path (major):**
  `variant_grammar` now requires each malformed name (`v4`, `v`, `vx`,
  `pc:80:3000v1`, `pc:80:cv1`) to be refused by `parse_name`, `clock`,
  `policy` and `config` alike.
- **New `variant_cli_boundary`,** through the binary with `--pairs 0`,
  so no game is played:
  - `ab:2:c100v2` and `ab:2:c<MAX_CLOCK_MS>v3` are accepted, with
    `control clock` in the header;
  - `ab:2:c100v4`, `ab:2:c0v1`, `ab:2:c<MAX + 1>v1` and `ab:2:c100v` are
    refused;
  - `ab:2:c100v2` with `--nodes 2000` is refused.
- **Results:** 3 tests fail against the stub (`variant_grammar`,
  `variant_wiring`, `variant_cli_boundary`); the rest of the tools suite
  passes. Clippy and rustfmt are clean.

## GREEN

- **`tools/src/agents.rs`:**
  - one parser, `clock_field`, reads `c<ms>[v<k>]`: the ms must lie in
    1..=`MAX_CLOCK_MS`, and k must name a registered
    `ClockPolicy::variant`, 0 when there is no `v`;
  - `time_field` uses it for any `c` field, so `parse_name`, `config`,
    `clock` and `policy` all refuse the same malformed names;
  - `clock_spec` gives the clock and variant behind `clock` and `policy`;
  - `search` builds `clock_agent` with `CLOCK_POLICIES[policy(name)?]`.
- **Results:**
  - `tools/tests/clock.rs`: 27 passed, 1 ignored;
  - `scripts/check.sh`: exit 0, 473 passed, 0 failed, 15 ignored.
- **Budgets:** engine 1,440 of 1,500; tools **1,498 of 1,500**, which
  leaves 2 lines; trainer 2,465 of 2,500. The book gate (#156) needs no
  tools change, since its `+book` grammar landed in #162.
