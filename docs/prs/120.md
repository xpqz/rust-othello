### Golden fingerprint of v1.0.0

Generated from a detached worktree at tag `v1.0.0` with an uncommitted
`tools/examples/golden_probe.rs` in that worktree:

```sh
git worktree add /tmp/othello-v1.0.0 v1.0.0
cargo run --release --quiet \
  --manifest-path /tmp/othello-v1.0.0/tools/Cargo.toml --example golden_probe
git worktree remove --force /tmp/othello-v1.0.0
```

The probe reads `bench/corpus.txt`, uses the explicit v1.0.0 configuration
`SearchConfig { eval: othello::eval::evaluate, endgame_threshold: 14,
ordering: true }`, and records `(best, score, nodes)` from
`search_limited(..., SearchLimits::depth(8))`. It does not call
`SearchConfig::standard()`, so the fingerprint will not follow the later
evaluator switch. Pass and terminal roots follow the existing corpus
convention: a pass root is searched after `pass(board)` and its score negated;
a terminal root uses `terminal_score(final_score(board))`. `best = 255` marks
a root with no move (pass or terminal); terminal `nodes = 0`.

Committed as `tools/tests/golden.rs` (`golden_v1`). The test runs in the normal
debug suite and takes about 7.7 s.

Probe source:

```rust
use othello::board::{Board, final_score, is_terminal, legal_moves, pass};
use othello::eval::evaluate;
use othello::score::terminal_score;
use othello::search::{SearchConfig, SearchLimits, search_limited};

fn main() {
    let config = SearchConfig {
        eval: evaluate,
        endgame_threshold: 14,
        ordering: true,
    };
    let path = concat!(env!("CARGO_MANIFEST_DIR"), "/../bench/corpus.txt");
    for line in std::fs::read_to_string(path).unwrap().lines() {
        if line.starts_with('#') {
            continue;
        }
        let mut parts = line.split_whitespace();
        let me = u64::from_str_radix(parts.next().unwrap(), 16).unwrap();
        let opp = u64::from_str_radix(parts.next().unwrap(), 16).unwrap();
        let board = Board { me, opp };
        let (best, score, nodes) = if is_terminal(board) {
            (255, terminal_score(final_score(board)), 0)
        } else if legal_moves(board.me, board.opp) == 0 {
            let result = search_limited(pass(board), SearchLimits::depth(8), &config);
            (255, -result.score, result.nodes)
        } else {
            let result = search_limited(board, SearchLimits::depth(8), &config);
            (result.best, result.score, result.nodes)
        };
        println!("{me:016x} {opp:016x} {best} {score} {nodes}");
    }
}
```
