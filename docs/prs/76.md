# Issue 76: Add search, score, and CLI tests

## RED

Issue: #76 — Add search, score, and CLI tests.

Test added in `tests/search.rs`:

- `double_no_move`: the parent `me = a1 | c1 | e1`,
  `opp = b1 | d1 | f1 | g1` has exactly one legal move, `h1`. Playing it
  fills rank 1 and flips `f1` and `g1`, leaving a child with 56 empties where
  neither side has a move. The child scores `-60` (2 discs to 6, winner takes
  the empties), `terminal_score` is `-6000`, and negamax at depth 1 returns
  `6000`.

Expected failure: none. Depth-zero terminal, pass-in-tree, horizon terminal,
fail-soft, caller roots, minimax equivalence, score bounds/overflow, and the
CLI perft/scripted-game tests already landed in #73 and #75. This issue adds
the missing double-no-move terminal fixture and closes the Phase 2 test gate.

## Intended behaviour

- A legal placement can leave a terminal position with empty squares, so the
  test checks that search resolves the child through `terminal_score`, not the
  heuristic.
- The final score follows the winner-gets-empties rule: the side with 2 discs
  loses to the side with 6 and the 56 empties, giving `-60` disc difference
  and `-6000` centidiscs.
- No production code or test-only hooks are added.
