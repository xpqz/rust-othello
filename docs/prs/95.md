# Issue 95: Dynamic corner risk without static X/C penalties

## RED

Tests added in `tests/eval.rs`:

- `corner_risk_while_empty`: b2 (X) scores 50 and b1 (C) scores 80 while a1
  is empty.
- `corner_risk_disappears`: occupying a1 removes the X/C penalty for either
  side; b2+a1 and b1+a1 score 299, and b2 against an opponent-owned a1 scores
  -101.

Expected failure: `corner_risk_disappears` fails now because the static table
keeps penalising X/C squares after the corner is occupied.

## Intended behaviour

- Replace the table's static X/C values (-50/-20) with the neutral -1.
- While the adjacent corner is empty, subtract 49 from an owned X, 19 from an
  owned C (and symmetrically for the opponent). Once the corner is occupied,
  no penalty and no double count remains.
- Safe X/C ownership is not rewarded; it stays a later option.
