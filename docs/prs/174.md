# Issue 174: Side panel overflow lets the board cover the GUI side panel

## RED

Reported from the installed release app: at the default 960×700 window
the board covers the left part of the side panel and the panel content
is clipped on both sides.

Cause, from logged layout rects: the panel is `exact_size(320.0)` with
two 18 pt margins, leaving 248 pt for content. The row
`engine clock (next game)` (slider, value box and caption) is wider than
that. In egui 0.37, `Panel::show` clamps an overflowing response rect
to the panel size by keeping its overflowing right edge, so the parent
cursor stops at x ≈ 735 instead of 640. The central panel then claims
96 pt of the panel's space and paints the board over it.

Test seam: `App::layout` holds the body of `eframe::App::ui` and returns
the panel's content rect and the central panel's rect. No behaviour
change.

Test written (`gui/src/main.rs`):

- `panel_not_covered`: at 960×700 and the 720×520 minimum window, with
  a search report shown, the central panel ends at or before
  `width − 320` and the panel content lies within the panel's span.

Expected failure (`cargo test --release --locked --manifest-path
gui/Cargo.toml`): `panel_not_covered` fails with
`960x700: board area [[0.0 0.0] - [735.2 700.0]] enters the panel at 640`.
The other six GUI tests pass. GUI clippy with warnings denied passes.

Intended behaviour: keep every panel row within the content width, for
example by putting each slider's caption on its own line above the
slider, and letting rows of buttons wrap. The board then fills only the
space left of the panel.

## GREEN

The user approved the RED stage in chat ("Proceed"); no review file was
written for it.

Changes in `App::panel_ui` (`gui/src/main.rs`):

- Each slider's caption is now a label on its own line above the slider:
  "Engine clock (next game)" and "Solve at empties". The slider rows
  hold only the slider and value box, which fit the 248 pt content width.
- The new-game buttons use `ui.horizontal_wrapped`, so they stack when
  they don't fit on one line.

Results:

- `cargo test --release --locked --manifest-path gui/Cargo.toml`: all
  7 GUI binary tests pass, including `panel_not_covered`, and all 6
  overlay tests pass.
- `./scripts/check.sh` exits 0: formatting, clippy, all crate suites
  and budgets pass. The suites report 53 `ok` results and no failures.
  Tools are at 1,483 lines and the trainer at 2,464; the engine is
  unchanged.
- A screenshot of the release build at 960×700 shows the full panel
  beside the board with no overlap or clipping.
