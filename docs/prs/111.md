# Issue 111: Calibrate the ProbCut error model

## RED

Read the ProbCut design’s Fitting, σ-model, supported-domain and shallow-depth
sections, plus PLAN’s interruptible-job requirements.

New `tools/examples/fit_probcut.rs` tests, run by
`cargo test --release --manifest-path tools/Cargo.toml --example fit_probcut`
and added to `scripts/check.sh`:

- seeded OLS on `v_d = 0.9·v_s + 20 + N(0, 100²)` recovers a, b and σ;
- the decision simulator counts true/false high and low cuts on a hand-built
  `(v_s, v_d, α, β)` table, using `ProbCut::high/low`;
- Clopper-Pearson upper bounds pin 0/200 and 0/75;
- the 70/30 split is game-grouped, disjoint, stable and approximately 70%;
- Zobrist deduplication keeps the first row per key.

Expected failure:

```text
error[E0425]: cannot find function `ols` / `decision_counts` / ...
```

## Intended implementation

`tools/examples/fit_probcut.rs` will implement the staged, journaled pipeline:
self-play games, deterministic line/variation sampling, per-position
measurements through the public `negamax`/`Ctx`/table API, OLS and σ-model fits,
held-out decision calibration with Clopper-Pearson bounds, the supported-domain
selection, the d′ comparison, and the final `ProbCut::new(...)` line in
`docs/tuning/probcut_fit.log`.

Interrupt/resume coverage, including SIGKILL mid-measurement, truncated-tail
replay and header mismatch, will be added with the pipeline implementation.

## Budget

The fitting example is uncounted data-generation code; no engine change
expected.
