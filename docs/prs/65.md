# Issue 65: Add LOC and test-separation guards plus check script

## RED

No test stage: this is build-guard setup work under the AGENTS.md exception.

## Implementation

- Added `tests/budget.rs`:
  - counts formatted engine + CLI source lines, excluding blank and
    comment-only lines, including block comments;
  - asserts the engine total is at most 999;
  - rejects `build.rs`, `rustfmt.toml`, `.rustfmt.toml`, `#[cfg(test)]`,
    `include!`, and `#[path]` in production source;
  - prints the actual count.
- Added a minimal tools crate and `tools/tests/budget.rs`, which applies the
  same rules with a 600-line ceiling. The crate currently has no production
  lines.
- Added executable `scripts/check.sh`: formatting, clippy, tests, and both
  budget tests for engine and tools.


Negative checks, with temporary source files removed afterwards:

## Intended behaviour

The guard enforces the 999/600 ceilings, reports the real counts, and blocks
test code or hidden source from production paths.
