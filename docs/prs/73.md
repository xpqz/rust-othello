# Issue 73: Implement negamax/alpha-beta with terminal-before-cutoff and fail-soft

## RED

Issue: #73 — Implement negamax/alpha-beta with terminal-before-cutoff and
fail-soft.

Tests added in `tests/search.rs`:

- `depth_zero_terminal`: a terminal win at depth 0 returns
  `terminal_score(final_score) = 6200`, not the heuristic value `80`.
- `horizon_terminal`: a 63-disc position whose only move fills the board
  returns the exact terminal value `6200`; the child's heuristic is `-6112`
  and its terminal value is `-6200`, so the check distinguishes them.
- `pass_in_tree`: a no-move, non-terminal root recurses through `pass` at the
  same depth, agrees with plain minimax, and negates the passed search.
- `fail_soft`: with `alpha = 5000`, the start position at depth 1 still returns
  the best child value `297` (the REVIEW-r2 value for this evaluator), not the
  incoming alpha.
- `minimax_equivalence`: plain minimax agrees with negamax at depths 1-4 on
  100 seeded positions.
- `caller_roots`: a forced-pass root is never given to `search`; the caller
  searches the passed position and negates the score. A terminal root has no
  legal move and ends the game.
- `terminal_root_panics`: calling `search` on a terminal root panics with
  `"legal root move"`, pinning the precondition.
- `depth_zero_fallback`: `search(..., 0)` returns the lowest legal move
  (`d3`), the static evaluation, `depth = 0`, and `Fallback`.
- `complete_depth`: `search(..., 3)` returns the negamax score, `depth = 3`,
  `Complete`, `solved = false`, a legal best move, and non-zero nodes.

Expected failure:

```text
error[E0432]: unresolved imports `othello::search::Ctx`,
```

The failure is intended: `src/search.rs` is empty.

## Intended behaviour

- `SearchConfig { eval: fn(Board) -> i32, endgame_threshold: u32 }` carries the
  evaluator from the start. The threshold is unused until the solver arrives.
- `Ctx { config, nodes }` is the mutable node context; `Ctx::new` starts it.
- `negamax` resolves terminal and pass before the depth cutoff, passes at the
  same depth, tracks `best` separately from `alpha` (true fail-soft), and
  returns `Option<i32>`; Phase 2 never aborts, so it is always `Some`.
- `search` requires a legal root move and panics otherwise. At depth 0 it
  returns the deterministic first-legal fallback and the static score with
  `Fallback`; at depth >= 1 it returns `Complete`, `solved = false` (the exact
  solver is Phase 6).
- `SearchLimits`, deadlines, and partial results are #83; `SearchStatus` has
  the full three variants from the start.
- The root is not counted as a node; interior nodes are.

  `opp = a1 | c1` in both `pass_in_tree` and `caller_roots`.

  `-negamax(play(START, best), 2, ...)`.

  returns 297, not 0.
- `minimax_equivalence` samples every 13th visited position plus every
  no-move position, across up to 400 playouts, so midgame and late positions
  are represented.
