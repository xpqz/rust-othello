# #173 — Remove the book runtime path from engine, GUI and match tool

Epic #172. This follows #171: the book stays disabled in CLI and GUI
play, so its runtime path comes out of the shipping engine to reclaim
budget. The trainer, the historical journals and both book assets stay
for research.

## RED

### Intended behaviour

**Engine:**

- Delete `src/book.rs` (92 lines), its `pub mod book`, `assets/book.bin`
  (85,019 bytes) and `SearchConfig::book`.
- `SearchAgent::choose` calls `search_tt` directly.
- The current engine count is 1,491 production lines; the drop is
  measured in GREEN.

**GUI:** the engine thread calls `search_tt` directly.

**Match tool:** the agent grammar no longer accepts a `+book` suffix,
and `config` no longer sets a book flag.

**`book_trace`:**

- `--book` takes `off` or an asset path; `embedded` is refused before a
  journal exists.
- The tool carries the retired lookup verbatim as `book_lookup`,
  including the symmetry numbering and tie order. That keeps traces of
  the archived r3 asset identical to the embedded book's.
- The archived r3 asset `docs/tuning/book_ext/book.bin` has sha256
  `65bf818f…ea74`, identical to `assets/book.bin`.

**Unchanged:** the trainer (`trainer/src/book.rs`, which never used the
engine lookup), journals, `docs/tuning/book_diag/book_r0.bin` and the
r3 archive.

### Tests written

`tools/examples/book_trace.rs`; `book_lookup` is a stub returning `None`:

- `lookup_manifest`:
  - the archived asset equals the encoding of the 7,729 records in
    `docs/tuning/book_manifest.txt`, sorted by key;
  - every record answers in all 8 orientations with its value, and with
    an image of its move under a symmetry taking the stored board to the
    asked one.

  This is the contract formerly in `tests/book.rs`
  (`manifest_orientations`, `asset_manifest`).
- `lookup_misses`:
  - returns `None` for an empty asset, a ragged asset, a board with no
    legal move, a stored square of 64, an illegal stored square, and a
    deep position that is not stored;
  - answers a synthetic legal hit with its value.
- `command_embedded_retired`: `--book embedded` errors and creates no
  journal.
- `archived_reproduces_embedded`: `start` traced at 20,000 nodes with
  `--book docs/tuning/book_ext/book.bin` gives exactly the game records
  of `docs/tuning/book_diag/embedded_start_20k.journal`.
  - That fixture was traced with `--book embedded` from `affb6ed` before
    any removal.
  - It passes in RED, through the engine lookup, and must still pass
    after the switch.

`tools/tests/clock.rs`:

- `clock_grammar`: `pc:80:c5000+book`, `pc:80:3000+book`, `ab:2+book`
  and `pc:80:c13000v3+book` move from accepted to refused.
- `config("pc:80:3000+book" | "pc:80:c5000+book")` must error.
- `variant_grammar` loses its `+book` case.

### Expected failures

- `cargo test --release --example book_trace` gives 16 passed and 3
  failed: `lookup_manifest`, `lookup_misses` and
  `command_embedded_retired`. The first two fail on the stub; the third
  because `embedded` is still accepted.
- `cargo test --release --test clock` (tools) gives 26 passed and 1
  failed: `clock_grammar`, because `+book` is accepted.

Formatting and clippy with warnings denied are clean. The stub carries
an `allow(dead_code)`, which is removed in GREEN.

### Removed with the code in GREEN

These tests exercise only the removed runtime path:

- `tests/book.rs` (engine lookup and `book::play`); its asset contract
  moves to `book_trace` as above.
- `tests/clock.rs::clock_book_hit`.
- Tools `tests/clock.rs::book_charged`.
- GUI `engine_book_policy` and `engine_book_path`.
- `book_trace::asset_paths`; its search-only half is kept with an empty
  asset.

The `book: false` fields in `SearchConfig` literals across the
workspace go too. `trace_matches_production` keeps its book-off case:
the production agent has no book to compare against, and
`archived_reproduces_embedded` covers the book case.

Documentation: the `docs/design/book.md` § Engine and any `+book`
usage notes get a short "removed in #173" note. Historical reports are
left as written.
