### Worktree and order

Run from a dedicated worktree pinned at the approved commit; journals stay

### Interval definition

“Elo lower bound > 0” means the lower end of the 95% pair-bootstrap interval
printed by `match`/`report` (10,000 resamples) is positive.

## Results: validation failed at the first gate

Equal-nodes gate (200 pairs, seed 115, nodes 1,965,089, jobs 5):

```text

mean 0.5262 interval [0.4875, 0.5663] bootstrap
```

The Elo lower bound is **−8.69**, not > 0, so the pre-registered equal-nodes
gate fails. Per the stopping rule, the 500 ms and 3 s gates were not played,
no other t was tried, and `standard()` stays `probcut: None`.

The run was interrupted once by the user for sleep and resumed from the same
journal; the final segment took 2313.60 s, with 980.94 s in the interrupted
segment (84 pairs retained). Final log:
`docs/tuning/probcut_validation_nodes.log`.

Validation has now been seen once. Any later attempt is a second look and
must be a new issue declaring that. The final set remains untouched.
