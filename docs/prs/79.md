## Intended behaviour

- `baselines.rs` contains a self-contained `eval_phase2` with its own table,
  scale of 100, and clamp to `[-6400, 6400]`; it does not call or track the
  engine's `evaluate`. `phase2_config()` pairs it with threshold 12 and
  `PHASE2_DEPTH = 4`.
- `main.rs` implements `match --a NAME --b NAME [--pairs N] [--seed S]` with
  hand-rolled parsing. Agents are `random`, `greedy`, `phase2`, and
  `ab:<depth>`; `ab` uses the current evaluator. Factories construct fresh
  agents for each game.
- Each pair plays both colour assignments from the same opening (the start
  position until #80 supplies frozen openings), converts game scores to
  1/0.5/0 points, and reports via `stats::report_with` with the default
  resample count.
- `phase2:<time-ms>` and time control are deferred to #84; openings and
  ordered logs are #80.
