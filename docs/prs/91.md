# Issue 91: Add WDL narrow window and exact widening

## RED

Issue: #91 — Add WDL narrow window and exact widening.

Tests added in `tests/search.rs`:

- `wdl_sign_matches_exact`: 20 seeded 6–8-empty positions; the WDL sign
  agrees with exact, and a proven draw is 0.
- `wdl_stores_bounds`: finds win/loss/draw positions; `solve_wdl` with a table
  stores an `Endgame`, depth-0 root entry: `Lower` for a win, `Upper` for a
  loss, and `Exact 0` for a draw.
- `wdl_cancellation_falls_back`: a one-node budget on an endgame root returns
  `Fallback` with `solved = false`.
- `wdl_widening_matches_exact`: 20 seeded positions solved through the root
  trigger match the exact score, with `Complete`, depth 0, and `solved`.

`Ctx::set_table` was added so the tests can attach a table when calling the
solver directly.

Expected failure:

```text
error[E0432]: unresolved import `othello::search::solve_wdl`
```

## Intended behaviour

- `solve_wdl(board, ctx) -> Option<i32>` runs the exact mode with window
  `(-1, 1)`, returns the sign, and stores the root as an endgame bound:
  `Lower` for a win, `Upper` for a loss, `Exact 0` for a draw. It never
  stores an exact non-zero WDL value. `None` propagates cancellation.
- The root trigger runs WDL first, then widens: `(0, INF)` for a win,
  `(-INF, 0)` for a loss, `(-1, 1)` for a proven draw. The exact root result
  is `Complete`, depth 0, `solved = true`.
- Interior nodes continue to use the shared exact/heuristic mode; no interior
  WDL entry point.

## Review responses

- Added `wdl_only_partial`: a decisive seeded 6–8-empty position, the WDL
  pass's node count, then `search_limited` with `max_nodes = wdl_nodes + 1` so
  widening aborts. It asserts `Partial`, `solved = false`, depth 0, and the
  exact sign.
- `Ctx::set_table` will be used by the production root trigger, not only by
  the tests.
- `wdl_sign_matches_exact` pins `wdl == wdl.signum()` (only -1, 0, 1).

## GREEN

- `solve_wdl` runs exact mode at `(-1, 1)`, returns `signum`, and stores the
  root as `Endgame` depth 0: `Lower` for a win, `Upper` for a loss,
  `Exact 0` for a draw.
- The root trigger runs `solve_wdl` itself, re-enables exact mode, and widens
  to `(0, INF)` for a win, `(-INF, 0)` for a loss, or `(-1, 1)` for a draw.
  A widening abort returns `Partial`, depth 0, `solved = false`, with the WDL
  sign; a WDL abort returns the existing `Fallback`.
- `Ctx::set_table` is now used by the production trigger.
- `root` takes an alpha/beta window and carries exact-mode depth unchanged.
