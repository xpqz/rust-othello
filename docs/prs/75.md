## RED

Issue: #75 — Implement CLI board printer, play, perft, and bench.

Tests added in `tests/cli.rs`:

- `printer_roundtrip`: `parse(render(board, black))` equals the original board
  and side for the start in both colours, the pass fixture, and a full board.
- `perft_three`: `othello perft 3` prints `56` and exits successfully.
- `perft_invalid`: `perft x` and `perft 11` fail with a `depth` error.
- `usage_is_shown`: no arguments fail with a `usage` message.
- `eof_exits`: `play` with immediate EOF exits successfully after printing the
  board.
- `bench_runs`: `bench --depth 2` prints the depth and node count.
- `illegal_input`: `zz` and the empty-but-illegal `a1` print `Illegal move`
  and the process still exits cleanly at EOF.
- `scripted_game`: simulates a complete game with a human black playing the
  lowest legal square and the greedy agent as white, then feeds exactly those
  human moves to `play` and checks the final `Game over. Black X, White Y.`
  line.

Expected failure:

```text
error[E0432]: unresolved imports `othello::cli::parse`, `othello::cli::render`
```

The binary cases also fail today because `cli::run` is empty. The failure is
intended.

## Intended behaviour

- `othello play`: human is black, the greedy agent is white. The board is
  printed with file/rank coordinates, side to move, disc counts, and legal
  moves. The engine passes automatically; the human is prompted while they
  have no move and must type `pass`. EOF exits cleanly.
- `othello perft <depth>`: validates the depth (0-10) and prints the perft
  node count.
- `othello bench [--depth N]`: fixed-depth search from the start, printing
  `depth`, `score`, and `nodes`. Default depth is 4.
- Unknown commands and invalid arguments print a usage or depth error to
  stderr and exit non-zero.
- `cli::render(board, black_to_move)` and `cli::parse(text)` are the exact
  printer/parser pair used by the round-trip test.
- No dependencies are added; argument parsing and input handling are
  hand-rolled with `std`.
