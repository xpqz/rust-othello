## Gate 2 amendment and result

The original `--max-load 4` command was invalid: four match threads hold the
load at or above four, so the first attempt voided 16 game records (8 pairs).
That run was stopped, set aside, and no score was examined.

With the user's decision, gate 2 was relaunched unchanged except
`--max-load 6` (four threads plus room for two ambient cores). The launcher
waited for load < 2. First pass 22:36–01:17: 57 void pairs (114 games), no
scores read. Second pass 01:17–01:27: the same command replayed the 57 void
pairs, none void. All 1,000 pairs valid.

```text
pairs 1000 games 2000 W 1014 D 68 L 918
mean 0.5240 interval [0.5075, 0.5403] bootstrap
elo [5.21, 28.03]
```

Lower bound **5.21 > 0**: gate 2 passes. The first pass summary
(Elo [4.52, 27.33]) counted void pairs and is not the gate result.
