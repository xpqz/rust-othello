Issue: #68 — Implement perft utility for CLI and tests.

Tests added in `tests/perft.rs`:

- `perft_start_shallow`: exact start-position counts for depths 1-8
  (`4, 12, 56, 244, 1396, 8200, 55092, 390216`).
- `perft_start_deep` (`#[ignore]`, release-only): depths 9-10
  (`3,005,288`, `24,571,284`).
- `perft_zero_is_one`: `perft(b, 0) == 1` on the start and on a full board.
- `perft_pass_consumes_ply`: `{me: b2, opp: a1|c1}` has no move for `me` and
  two for `opp`; `perft(1) == 1` (the pass is a node) and `perft(2) == 2`
  (the two replies).
- `perft_early_terminal_counts_one`: a board whose only discs fill the first
  rank (`me: a1|c1|e1|g1`, `opp: b1|d1|f1|h1`, 56 empties) is terminal, so
  `perft` is 1 at any depth. The non-empty board makes the terminal rule, not
  the depth-0 base case, the reason.

Expected failure:

```text
error[E0432]: unresolved import `othello::perft::perft`
```

The failure is intended: `src/perft.rs` is empty.

## Intended behaviour

- `perft(board, depth) -> u64`: `depth == 0` is one node.
- When the side to move has no moves, recurse into `pass(board)` at
  `depth - 1`; the pass position is itself a node.
- A terminal position (neither side has a move) counts as one node when
  `depth > 0`.
- Otherwise sum `perft(play(board, sq), depth - 1)` over every legal move.

The CLI `perft` subcommand is wired in #75; this issue provides only the
shared `src/perft.rs` walk and its tests.
