## RED

Issue: #70 — Write naive reference move generator and flip routine in tests.

Tests added in `tests/reference.rs`:

- `start_opening_moves`: `Naive::legal_moves()` is exactly
  `{c4, d3, e6, f5}`, and `Naive::flips` is non-zero for each.
- `c4_post_move`: after `c4`, `me = e5` and `opp = c4 | d4 | e4 | d5`;
  `flips(c4) = d4`; `play` leaves the original board unchanged.
- `all_opening_replies`: the post-move reference boards equal the production
  boards for all four opening moves.

Expected failure:

```text
error[E0599]: no method named `legal_moves` found for struct `Naive`
error[E0599]: no method named `flips` found for struct `Naive`
error[E0599]: no method named `play` found for struct `Naive`
```

The failure is intended: the reference has only `start` and `bits` today.

## Intended behaviour

- `Naive::flips(sq) -> u64` walks each of the eight directions on the
  `[[i8; 8]; 8]` cells, keeps a run only when it ends on `me`, and returns the
  flipped squares as a mask.
- `Naive::legal_moves() -> u64` tests every empty square with `flips`.
- `Naive::play(sq) -> Naive` returns a new reference board with the move and
  its runs applied; it does not mutate the original.
- The start position is built from coordinates, not from `Board::START`, and
  the reference does not call production move generation or flipping.
