# Issue 112: Selective search modes, TT provenance, ProbCut check

## RED

Read design §§ Search modes, Insertion point, The check (steps 1-8),
TT provenance, Configuration/API, and tests 1-7, 9-10.

Tests added in `tests/search.rs`:

- `probcut_off_writes_no_selective_entries`;
- `exact_mode_ignores_probcut` (score, node count, zero counters);
- `high_and_low_cut_at_thresholds` (both counters and exact returned bounds);
- `unsuccessful_probes_match_full_width`;
- `probcut_domain_bypass` (depth and empties);
- `selective_search_writes_selective_entries`;
- `full_width_ignores_selective_entry`;
- `selective_root_contract_with_limits`.

Expected failures: missing `SearchConfig.probcut`, `Ctx.probing`,
`Ctx.probcut_*`, and `Domain::Selective`.

## Intended implementation

- Add the config switch, mode flag and counters.
- Add `Domain::Selective`; make heuristic TT cutoffs domain-aware and hints
  accept either heuristic domain.
- Run high/low null-window probes after the TT cutoff and before ordering,
  only in selective mode inside the supported domain; restore `probing` on
  every exit; count tries/cuts.
- Selective stores write Selective; full-width/probes write Heuristic; exact
  remains Endgame.
- `standard()` stays `probcut: None`; every explicit test/tools literal gets
  `probcut: None` rather than inheriting from `standard()`.
