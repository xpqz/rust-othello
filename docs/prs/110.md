# Issue 110: Add ProbCut parameters and threshold arithmetic

## RED

Read `docs/design/probcut.md` revision 2 in full before starting.

New `tests/probcut.rs` covers:

- validating constructor ranges: t 50–400, a 500–1500, ordered inclusive
  depth/empty ranges, depth min ≥ 3, and σ ≥ 1 throughout the domain for all
  three models;
- `shallow_depth(3..=12)` against the design table and even depth reduction;
- supported-domain boundaries in both dimensions;
- hand-computed high/low rounding with `a = 900`, `b = 30`, including negative
  numerators: high 689/23, low -645/-89;
- guards at `±EVAL_BOUND` and `±INF`;
- hand-computed σ for Linear, EdaxStyle and StageTable;
- saturated extreme coefficients without panics.

Expected failure:

```text
error[E0432]: unresolved import `othello::probcut`
```

## Intended behaviour

New `src/probcut.rs`, wired from `lib.rs`, with no `SearchConfig` or
`negamax` change:

- `ProbCut::new(...) -> Result<ProbCut, String>` is the only constructor.
- `SigmaModel` has the three design forms; StageTable uses six buckets covering
  empties 18–23, 24–29, …, 48+.
- `shallow_depth`, `supports`, `sigma`, `high`, `low` implement the design’s
  arithmetic with conservative ceil/floor rounding and guards on the
  transformed thresholds.
- All threshold arithmetic is i64; σ uses saturating i64 arithmetic so
  extreme accepted coefficients cannot panic in a debug build.
- Depth and empty ranges are capped at 64; the σ ≥ 1 check walks the finite
  supported grid rather than sampling only corners.

Existing search behaviour is untouched, so every existing test must pass
unchanged.

## RED review responses

- Added negative/positive numerator rounding, exact divisions, and a
  non-integer margin (`σ = 33`, m = 50).
- Added transformed-threshold guard boundaries: 6467 skipped, 6400 accepted,
  6402 skipped; mirrored at `-6400`.
- Extreme saturated coefficients now assert every high/low call returns
  `None`.
- EdaxStyle is fixed-point in thousandths for `a,b,c,q2,q1,q0`; `s` uses the
  same scale and final σ rounds up. Linear/StageTable remain integer
  centidiscs.
- Added accepted endpoint checks, depth/empty 65 rejections, and a StageTable
  below-18 bucket test.

## GREEN

- Added `src/probcut.rs` and `pub mod probcut` in `lib.rs`. No `SearchConfig`
  or `negamax` change.
- `ProbCut::new` validates t/a, inclusive depth/empty ranges, domain caps at
  64, depth min ≥ 3, and σ ≥ 1 over the full supported grid.
- `SigmaModel` has Linear (integer centidiscs), EdaxStyle (thousandths for
  `a,b,c,q2,q1,q0`; `s` at the same scale; σ rounds up), and the six-bucket
  StageTable (below 18 uses bucket 0). Doc comments state the units.
- `high`/`low` use saturating i64 arithmetic, ceil/floor toward the
  conservative side, and guard on transformed thresholds against

- Added the requested EdaxStyle case with non-zero `b_milli`, `c_milli`,
  `q1_milli`, `q0_milli` including negatives: σ(8, 30) = 957.
