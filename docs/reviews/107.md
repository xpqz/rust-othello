# Review: Issue 107 — Auto-pass the human when Black has no legal move

Verdict: **request changes** (one)

## Verified

- #106 was merged. This branch is based on the current `main`.
- The CLI change is right and minimal. When Black has no legal move, `play`
  prints `Black passes` and swaps without reading input, which is the same
  shape as White's pass branch. The old typed-`pass` arm is gone, so a typed
  `pass` is now always illegal: either moves exist, or input is never read.
  `illegal_input`'s `pass` case still holds. The engine stays at 999.
- The README notes automatic forced passes.

## Required

1. **`assert!(passes > 0)` depends on time.** Whether Black is ever forced to
   pass in `play_complete_game` depends on the moves White plays, and White
   is now the search agent at a **1 s wall-clock** limit. How deep it gets
   (and so which moves it picks) varies with machine speed and load, so the
   game varies too. The #106 demo game ended `Black 0, White 51`, a
   wipeout, so games without a Black pass clearly happen. The test passed on
   one run here, but on another machine, or under load, it can fail with
   nothing wrong. Remove that assertion, or make it log-only. A test that
   fails depending on timing is worse than no assertion.

   Deterministic coverage of the forced pass would need `play` to start from
   a given position or use a node-limited opponent, and neither exists
   (engine 999/999). So say in the notes that the auto-pass branch is
   exercised by `play_complete_game` only when the game happens to produce a
   Black pass. The regression it guards against (the CLI blocking on input
   at a forced pass) still shows up whenever one occurs.

## Nits (non-blocking)

- The White branch still says `.expect("greedy must move")`, but White is
  the search agent now. Use `"search must move"`.
- Process: this landed as one commit, with no RED stop. The notes give a
  reason (the old test would block). For a fix this small that is
  understandable, but AGENTS.md's exception covers only configuration and
  setup work.
