# Review of #165 — Engine clock policies and early exits

## RED review of `a491933`

**Request changes (RED).** The suite covers the cutoff boundary,
streak reset, exact-search behavior and when the forced shortcut
becomes active. Three tests need to distinguish wiring and policy
mistakes that would affect tuning.

### Major — The variant 3 fixture cannot distinguish cap 3 from cap 2

At `tests/early.rs:298`, the variant 3 fixture expects a target of
4,666 ms and a capped deadline of 8,750 ms. Both cap 2 and cap 3 hit
the same 8,750 ms quarter-clock ceiling. A variant that changes the
weight but accidentally keeps cap 2 passes.

Add a case such as 44 empties, threshold 18 and R = 34,000 ms. The
target is 4,000 ms and the deadline is 8,500 ms with cap 3. Cap 2
would give 8,000 ms. The existing example can still check the
variant-specific exit fields.

### Major — Exercise both settled rules when they are enabled together

The pure predicate tests enable stable or decided separately. The
registered variants 2 and 3 enable both. An implementation that only
checks decided when stable is disabled would pass the current suite
and erase the distinction between variants 1 and 2.

With `Early { stable: 3, decided: 2000, share: 25 }`, test that an
unstable move history with a decided score stops at the share cutoff.
Also check that a stable history with an undecided score stops. Include
`i32::MIN` in the pure score test to pin unsigned magnitude across its
public input range.

### Major — Verify that the agent uses its selected allocation

The allocation tests call `allot_with` directly. The forced-move tests
exercise the policy's shortcut. A clocked agent could implement the
shortcut and continue using variant 0 allocation on every search
without failing these tests. Add a discriminating assertion on
`clock_agent(..., variant_3).limits(board)` after `clock(R)`.
Use a multi-move position with different variant 0 and variant 3
limits, and check the exit fields alongside the numeric limits. Also
verify that the agent exposes the supplied fixed limits before that
first clock update.
