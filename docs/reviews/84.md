# Review: Issue 84 — Time controls, bench, and equal-node agent naming (RED)

Verdict: **request changes** (small)

## Verified

- #83 was merged and closed. This branch is based on the current `main`.
  fmt is clean for both crates.
- The RED tests fail as intended. `bench_time_controls` fails (the flags
  are unknown and there is no `nps`), and `timed_and_node_agents` and
  `node_limited_match` fail (unknown agent names and an unknown `--nodes`).
  Every other test still passes (cli 8/9, baselines 12/14).
- `time_ms = 0` and `max_nodes = 1` from `bench` must give depth 0, which
  exercises #83's fallback path through the CLI.

## Required

1. **`--nodes` could be ignored and the test would still pass.**
   `node_limited_match` checks reproducibility and that the output contains
   `nodes 100`, but the config line can print the flag while the agents run
   unlimited. Byte-identical repeats also hold without a node limit, because
   deterministic agents are deterministic anyway. Add a test that shows the
   budget bites: the same match with and without `--nodes 100` produces
   different game logs, or a `phase2` move under a 100-node budget differs
   from the unlimited depth-4 move. Also say in the notes whether `--nodes`
   is a budget **per move**, which is what equal-node matches need.

2. **The wall-clock smoke test is missing.** #84's acceptance includes a
   "tolerant 50ms wall-clock smoke", and the scope says it "allows
   max(50ms, 10%) overrun". The only time test uses `--time-ms 0`, which
   never touches the clock path past the first check. Add one smoke test:
   `bench --depth 30 --time-ms 200` (depth set so the deadline binds) must
   report elapsed ≤ 200 + max(50, 20) ms, and status not `Complete`. Check it
   against the printed `elapsed`, or time the process. Make it release-only
   if debug is too noisy. #85 can expand the matrix, but the acceptance
   item belongs here.

## Minor

3. **`elapsed` is never asserted.** The scope says bench reports nodes, nps,
   depth reached, and elapsed time. The test checks `depth` and `nps`. Add
   `elapsed`, and `nodes`.

4. **Malformed suffixes.** Add `ab:2:x`, `ab:2:`, and `phase2:x` as rejected
   with `unknown agent`, matching the `ab:x` and `ab:` cases from #79.

5. **Budget.** `cli.rs + main.rs` is at 160 of 170 and tools at 577 of 600.
   Bench flag parsing and the `:time` suffix go straight into those
   margins. Reuse `parse_depth`-style helpers and the existing
   `make_agent` / `describe` split rather than adding parallel parsers.

## Nit (non-blocking)

- The game log records seeds, key, opening, agents, and **score**, not the
  moves. So `assert_ne!(logs(&first), logs(&unlimited))` really compares
  final scores. If the 100-node and unlimited games happened to end with the
  same scores, the test would fail even though the budget took effect.
  Probably fine for this fixture. If GREEN trips on it, compare a played move
  or the reported depth instead of widening anything.
