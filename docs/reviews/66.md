# Review: Issue 66 — Implement Board, direction masks/shifts, and legal_moves (RED)

Verdict: **request changes**

## Verified

- The branch is based on the current `main`, after #65 was merged and closed.
- `cargo test --test movegen` fails with exactly the E0432 recorded in the PR.
- The fixtures I checked use the right coordinates. The start moves
  c4/d3/e6/f5 are bits 26/19/44/37, and `bit(file, rank)` follows the `a1 = bit 0`
  row-major rule.

## Required

1. **`start_board` copies the production constant instead of checking it
   independently.** It compares `Board::start()` with
   `(1 << 28) | (1 << 35)` and `(1 << 27) | (1 << 36)`, which are the same
   magic numbers the implementation will use. A swapped-colour or mis-indexed
   constant copied into both places passes. PLAN.md requires that "the tests
   build the same position independently from coordinates". The shared helper
   already exists: compare against `common::Naive::start().bits()`, or against
   `bit(3, 4) | bit(4, 3)` and `bit(3, 3) | bit(4, 4)`. The `let copy = start`
   line proves nothing that compiling doesn't. Drop it, or use `start` after
   the copy.

2. **The `legal_moves` fixtures don't cover the algorithm.** The start
   position only exercises the four orthogonal directions, and `line_moves`
   adds one more horizontal case. Nothing tests a diagonal, the six-step run
   limit, the edge masks inside `legal_moves`, or the landing-empty mask. Add
   hand fixtures. Each is one line, and I computed the expected results:
   - six-run limit: `me = a1`, `opp = b1..g1` → `h1`;
   - each diagonal: `me = a1, opp = b2` → `c3`; `me = h1, opp = g2` → `f3`;
     `me = a8, opp = b7` → `c6`; `me = h8, opp = g7` → `f6`;
   - wrap guard: `me = h1`, `opp = a2` → `0`. Without `NOT_A`, east of h1
     wraps to a2 and gives a false `b2`;
   - landing must be empty: `me = a1 | c1`, `opp = b1` → `0`;
   - a gap breaks the run: `me = a1`, `opp = b1 | d1` → `c1` only.

3. **There is no positive `N` shift.** `shift_edges` checks only that `N` falls
   off at a8. Add an interior case such as `a1 → a2`. Every other direction has
   both a positive case and an off-board case.

## Minor

4. **Full-board shift checks.** Single corner bits test each mask at one
   square. `shift(u64::MAX, d).count_ones()` should be 56 for E/W/N/S and 49
   for the diagonals. Those eight assertions catch any wrong or missing mask
   bit on a whole file or rank.

5. **A constant rather than a function.** PLAN.md asks for an "initial board
   constant". `Board::START` (a `const`) matches that, and it is also usable in
   `const` contexts. `Board::start()` is acceptable if you prefer it. Then say
   so in `docs/prs/66.md` so the plan and the code agree.

6. The intended-behaviour notes should say that `Board` derives `Debug`
   (`assert_eq!` needs it) alongside `Clone`, `Copy`, `PartialEq`, and `Eq`, as
   PLAN.md lists.
