`SearchConfig::standard()`. After this change it therefore collects selective

Changing the user-facing default must not silently change the reference
labels used for fitting/auditing ProbCut itself.

**4,194,304-entry table**, depth 8 and corpus board
`2002242e10000000:023c181028400000` (44 empties). Its labels are:

```
collected:  [1616, 694, 439, 583, -309, 352, -285, 467, -495]
full-width: [1616, 694, 439, 583, -309, 352, -285, 467, -360]
```

The reference uses the same evaluator, threshold 0, table size and sequence
