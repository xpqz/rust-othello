# Review: Issue 70 — Naive reference move generator and flip routine (RED)

Verdict: **request changes**

## Verified

- #69 was merged and closed. This branch is based on the current `main`.
  `cargo fmt --check` passes, and `tests/reference.rs` fails only with the
  expected E0599s (`legal_moves`, `flips`, `play`).
- The fixtures are correct. c4/d3/e6/f5, `flips(c4) = d4`, and the board
  after c4 (me = e5; opp = c4 d4 e4 d5) match the values already checked in
  #66 and #67.
- The start position is still built from coordinates. The #64 rescope
  (`tests/reference.rs` added to #70's Files) is recorded.

## Required

1. **The reference is tested only on the start position.** All four opening
   moves are single-direction, single-disc captures. A reference that gets
   edges, diagonals, multi-direction captures, or unanchored runs wrong
   passes every test here. #71 will then compare production against it, and
   any disagreement will be impossible to attribute. The hand fixtures
   already exist: #66's legal-move set (six-run, four diagonals, the h1/a2
   wrap guard, occupied landing, gap) and #67's flip set (multi-direction with
   an unanchored `d1` run, the h1 wrap, the six-disc run). Run them through
   the reference too. That needs:

2. **A `Naive::from_bits(me, opp)` constructor.** Item 1 needs it, and so does
   #71: the differential test must turn random production positions into
   reference boards, or replay every move in both, which is clumsy at the
   pass points. Add the constructor with a round-trip assertion,
   `from_bits(a, b).bits() == (a, b)`.

## Minor

3. **State the perspective rule.** `c4_post_move` expects
   `after.bits().0 == e5`, which means `play` returns the board from the
   opponent's view (cells negated), as production does. The
   intended-behaviour notes don't say so. Add one line, since #71 depends on
   both sides using the same convention.

4. **Pass.** #71's playouts need a reference pass (negate all cells). It is a
   one-line method, and #70 is the issue that owns the reference API.

5. **Carry the commitment from #69.** #69's approval deferred moving
   `nth_bit` and a `playout` helper into `tests/common/mod.rs` to this issue.
   It isn't mentioned in these RED notes. Plan it into GREEN, and have
   `tests/symmetry.rs` use the shared copy.
