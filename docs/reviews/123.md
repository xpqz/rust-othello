# Review: issue 123, label rule and labelling job, with pilot

## RED round 1 (commit 04c454d)

Verdict: **request changes**.

I worked `label_bands`, `final_result` and `disc_units` through by hand.
The expected values are right. Taking `solve` as a closure is a good
choice: the rule is tested without the solver.

Required:

1. **`pass_sign` does not contain a pass.** The engine's board is
   side-relative, so a pass swaps `me` and `opp`; the test uses one board
   value twice with different colour flags. And a position where the mover
   must pass never appears in `Replay.positions`. What the test checks is
   that an anchor value is converted to the other colour. Keep it, rename
   it for what it is, and add the real thing:
   - `pass_chain`: replay the known 59-move game with `wthor::replay` and
     label it with the real solver. For consecutive positions with at most
     10 empties, taking exact values from black's side, the value must not
     rise after a white move and must not fall after a black move, and the
     chain ends at the final result (+48 for black). A wrong colour across
     a pass breaks this. State in the notes at which plies the four passes
     fall; if none is inside the last 10 empties, widen the range until
     one is.
2. **The theoretical band is only tested with black to move.** Add a
   white-to-move position at or above P3 empties and expect −10.
3. **Band boundaries.** Positions with exactly 24, 23, 15 and 14 empties:
   theoretical, anchor, anchor, own value.
4. **The journal line is never read back.** The fit will depend on it.
   Add a round trip: the labels rebuilt from a journal line for the known
   game equal the labels from calling `labels` with the real solver.
5. **Header.** The journal header must carry the engine commit, the
   manifest or input hash, P3 handling and the solve threshold, per
   `docs/PLAN.md` § Interruptible long-running jobs. Add a test that
   resuming against a changed input is refused.
6. **Rejected games.** Say what the job does with an incomplete or illegal
   game (skipping it without a line is fine) and test it with one such
   game in the archive.
7. **`--jobs` and `--games`.** Run the resumed leg with `--jobs 2`, and
   assert that `--games 2` writes two lines.

For GREEN:

  the fixture, not the assertion.
