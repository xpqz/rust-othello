### Major — The negative assertions can pass while match accepts bad names

At `tools/tests/clock.rs:783`, an invalid name only needs to fail
`parse_name` or `policy`. Match validates its names through
`parse_name` and `config`, then identifies clock control through
`clock`. A parser that strips an invalid variant while `policy`
alone rejects it can satisfy the negative assertions. A zero-game
match can then accept the name without ever constructing the agent.

Require the public parsing paths to agree on malformed names, and
extend the existing zero-pair CLI boundary fixture for the new
grammar. Check a valid variant (the header must say `control clock`),
an invalid variant, and a valid variant combined with `--nodes`.
Check that a variant suffix preserves the clock's lower and upper
bounds, including an accepted maximum with zero games queued.
The setup and tuning runs use those same CLI paths and journal
identities.
