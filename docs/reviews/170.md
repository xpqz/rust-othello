# Review of #170 — Book trace tool

## RED review of `34b5a9b`

**Request changes.** The decision-level tests exercise the three book
modes and the basic record format. Add coverage of the trace and
journal the experiment will consume before GREEN.

1. **Major — Verify chronological move traces against production play.**
   `tools/examples/book_trace.rs:118` groups every Black decision before
   every White decision. The current fixtures bypass `traced_game`
   and compare `GameResult`, which contains only the score, plies and
   passes. Two distinct move sequences could satisfy that comparison.
   Use a fixture through the driver or its game-record path that
   compares the actual moves and colours with a recording wrapper
   around the production agents. Include a pass followed by another
   move by the same colour, and check the persisted trace's position
   keys and legal counts as the moves are replayed from the opening.
2. **Major — Cover the early diagnostic roots through the CLI.**
   `tools/examples/book_trace.rs:139` uses `positions::load`, which
   accepts only four- to eight-placement roots and skips blank lines.
   The approved design calls for one- to four-placement roots and a
   standard-start smoke case. The current tests pass short openings
   straight to the game harness, so they cannot catch this.
   Add RED coverage for the trace command's accepted representation of
   the start and for a one- to three-placement root. Preserve the
   existing opening parser's contract for its other callers.
3. **Major — Verify pair recovery and bind the journal to asset contents.**
   At `tools/examples/book_trace.rs:157`, an external book can change
   in place to a different asset with the same byte count, and the
   header will still match. An interruption after `pair:0` causes the
   driver to append a second `pair:0` on resume. A lone `pair:1`
   skips the whole pair. Add a committed fixture for interruption
   between games or a torn last record, and compare the result with
   an uninterrupted run. Require one valid record per colour, keep
   completed pairs intact, and reject a same-size asset replacement.
   Include the effective asset's content digest for both embedded
   and external books.
4. **Major — Reject a zero node cap before search.**
   `tools/examples/book_trace.rs:146` accepts zero, which disables the
   search node limit. Combined with `NO_DEADLINE`, this defeats the
   experiment's bound on work. Add a command-level regression that
   rejects zero before creating a journal or searching a game.
