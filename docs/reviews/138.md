## Accepted: steps 1 and 2

The decoder reads every fixed-size little-endian pair into an `i16` table
once, and stage slicing preserves the original slot addresses. The embedded
array's even fixed length and existing layout/length tests cover the ignored
empty chunk remainder. Memory cost of the decoded copy is disclosed.
`evaluate_wide` compares against direct file-byte reading on at least 100,000
playout positions, explicitly covering every stage. Combined with unchanged
independent feature-reference tests, it supplies an appropriate contract.

Padding changes only private row/sum storage. The builder fills 46 lanes;
the two spare lanes remain zero, and output zipping stops at the 46 offsets.
The public return type, indices, asset and trainer interfaces are unchanged.
Non-blocking documentation addition: padded rows cost another 8 KiB, and
each sum array four more bytes, alongside the reported 4 MB decoded table.

Another non-blocking wording correction: recursive exact search does not
evaluate leaves, but `search_tt` still calls `root_setup`, which evaluates
the root fallback once per search. Thus the exact benchmark does exercise
the evaluator, albeit with negligible frequency compared with midgame;
"exact search does not evaluate" is too broad as a literal explanation.

The benchmark v2 split is accepted as a clearly versioned search-only
measurement: clearing still occurs before every search and is separately
reported. Both before and after binaries use v2. Historical v1 results stay
end-to-end cold-table timings; subtracting an assumed clearing cost does not
create a new measured historical ratio. Similarly, dilution of a ratio is
conditional on comparable clearing costs, not guaranteed for every old run.

Independently audited all 400 rounds of the original v1 experiment: 21 pairs
meet midgame spread limits and none meet both exact limits, as stated. These
do not count toward the new gate. Audited all 180 v2 rounds:

- Step 1 qualifying pairs 4, 5, 8 give midgame ratios 1.1044, 1.0882,
  1.0983; all ordinary timing conditions pass.
- Step 2 qualifying pairs 5, 8, 10 give 1.0344, 1.0297, 1.0312; all other
  conditions pass. All ten pairs favor padding, so the recorded marginal-
  gain rule applies, without claiming the 5% bar was passed.
- Every round preserves 8,556,688 midgame and 7,001,000 exact nodes.
