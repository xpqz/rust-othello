## Command amendment (binding)

`match` prints the seed, nodes and bootstrap summary, but not the commit,
the wall-clock time or the job count, and `>` truncates the log every time
the command is re-run after an interruption. Use:

```sh
cd <worktree>
{ git rev-parse HEAD; date; /usr/bin/time -p cargo run --release --manifest-path tools/Cargo.toml -- match \
  --a pc:<t> --b pc:off --openings bench/openings_tune.txt \
  --pairs 200 --seed 114 --nodes 1965089 --jobs 5 \
  --max-load 5 --out docs/tuning/probcut_tune_<t>.journal; } \
  >> docs/tuning/probcut_tune_<t>.log 2>&1
```

Each resumed segment then appends its own commit, start time and elapsed
time. The total wall-clock is the sum of the segments. The final summary is
computed from the journal, so it covers all 200 pairs.
