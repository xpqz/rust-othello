## Required

1. **The production RNG has no known-answer test.** It is the single source of
   reproducibility for tests and tools, yet nothing pins its output. Any
   change to a shift or the constant would pass the current smoke test. Add a
   vector, for example `Rng::new(1)` yields `0x47E4CE4B896CDD1D`,
   `0xABCFA6A8E079651D`, `0xB9D10D8FEB731F57`, and pin seed zero's first
   output (`0x0D83B3E29A21487A`).

2. **The transform loop asserts nothing.** `let _ = transform(...)` only
   proves the code compiles. Either add a minimal check, such as the image of
   `a1` and `b1` under each symmetry (which fixes orientation and catches a
   swapped `Rot90`/`Rot270`), or leave the transforms to #69 (see 3).

3. **The D4 transforms overlap #69.** #69's scope is exactly "test-only Sym
   enum ... and transform(board, sym), plus square transform, in
   tests/common/mod.rs". This PR implements that, so #69 would be left with
   only the property tests. Pick one owner. Either update #69's scope to
   "symmetry property tests; transforms exist", or move the transforms out
   of this PR. Don't let two issues claim the same code.

4. **`Factory` is a no-op wrapper, and there is no reset.** `Factory<F>` just
   calls a closure, which is already a factory. The PR says "per-game agent
   creation and reset", but nothing resets anything, and there is no agent
   type yet to build or reset. Remove it and move "agent factory/reset
   helpers" to the issue that introduces the agent trait in `agents.rs`.
   Don't ship an abstraction with nothing to abstract over.

## Minor

5. **`seeded` adds nothing.** `seeded(s)` is `Rng::new(s)`. Use `Rng::new`
   directly and drop the wrapper.

6. **`format_bits` is only checked for line count.** Assert the exact start
   string. It is eight short lines, and it pins rank 8 at the top and `X` for
   the side to move.

7. **Dead code once `common` is shared.** Each test crate that does
   `mod common;` and uses only part of it will trigger `dead_code`, and clippy
   `-D warnings` will fail. Today only `invariants.rs` uses it. Decide the
   policy now, for example `#![allow(dead_code)]` at the top of
   `tests/common/mod.rs`, which is the usual Rust idiom for shared test
   modules, so the next issue doesn't trip over it.

8. **A `Sym::ALL` constant.** The eight-variant list in the smoke test will be
   needed again in #69 and in the tools crate. A `pub const ALL: [Sym; 8]`
   keeps it in one place.

## Nits (non-blocking)

- `transform_orientation` checks only `a1` for seven of the symmetries, and
  `a1` cannot tell `Rot90` from `FlipH` (both give h1), `Rot270` from `FlipV`
  (a8), or `Rot180` from `FlipAnti` (h8). `FlipDiag` fixes `a1`. Using `b1`
  for all eight distinguishes every pair:
  h2, g8, a7, g1, b8, a2, h7, and b1 for Identity. Order and commutation tests
  in #69 will not catch `FlipAnti` implemented as `Rot180`, because that is
  still a valid symmetry. Either use `b1` here, or have #69 assert the eight
  images are distinct.
- `pub type Rng = othello::rng::Rng;` in `common` is a pure alias.
  `tests/rng.rs` could import `othello::rng::Rng` directly. Keep the alias
  only if `common` is meant to be the one import point.
- `tests/rng.rs` is not in the PLAN.md file layout. Add a line there so the
  plan stays in sync.
