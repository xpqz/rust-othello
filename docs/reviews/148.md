## Major: screen options silently accept invalid controls

Location: `tools/examples/probcut_screen.rs:98–105,108–147`, `value`/`run`.

The lookup parser consumes only the first occurrence of each known flag and
never validates the remaining argument list. An optional flag with no value
silently takes its default. Independently reproduced through the built CLI:

- `nodes --t 80 --t 200`: exit 0 and a **passing t=80** result, despite the
  ambiguous repeated candidate and t=200 failing the registered node screen.
- `nodes --t 80 --typo 9`: exit 0 and a normal passing report.
- `depth --t 80 --ms 0 --jobs`: exit 0, uses the default worker count and
  reports two 50-position arrays, instead of rejecting the missing value.

Parse the complete argument list before loading positions or searching.
Reject unknown/repeated/value-missing flags and command-inappropriate options;
validate the worker count with checked conversion and a sensible positive
bound rather than silently replacing zero or permitting arbitrary spawning.
Add regressions for the demonstrated invalid invocations. Defaults are for
absent options, not supplied options missing values. This is the same
measurement-control reliability issue already corrected in the fitter.

This does not invalidate the recorded well-formed node invocations: their
exact totals reproduce independently. Do not rerun the long tuning job just
to test parser rejection.

### Major: repeated games are counted as independent Wilson trials

Location: `tools/examples/probcut_fit.rs`, `replay` audit sample loop and
per-depth `wilson_upper` calls; `docs/tuning/probcut2_replay.log`.

Canonical position deduplication does not remove repeated WTHOR games.
Independent reconstruction of the actual replay population finds **1,086
positions from 1,070 games**: 1,054 games contribute once and 16 twice.
Three repeated-game pairs are even within the same empties bucket; the
other repeats cross buckets. All positions contribute at every reported
depth. The current per-depth Wilson calculation treats all 1,086 outcomes
as independent Bernoulli trials despite their common-game clustering.

The approved design explicitly identifies distinct games, rather than
position uniqueness alone, as the independence assumption behind Wilson
bounds. The fit enforces one game per cell; the replay bypasses that step
and also pools buckets for its per-depth intervals. Thus the printed
“upper95” bounds are nominal binomial bounds, not established 95% coverage
under the registered evidence-unit assumption.

Use independent game units for the advertised intervals (for example the
lowest-unit position per game at each depth), report Wilson bounds on
one-game-per-cell samples and keep pooled rates descriptive, or use an
appropriate game-cluster interval. Alternatively explicitly qualify these
as nominal independence-assuming bounds rather than calibrated 95% bounds.
Add a small repeated-game fixture protecting the chosen treatment. Keep the
frozen model/domain and tuning rule unchanged: this is a reporting/statistical
unit correction, not a new audit-driven model-selection opportunity.

The existing point counts remain correct for their declared population of
positions. No tuning restart or new strength experiment is requested.
