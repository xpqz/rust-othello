## Nit (non-blocking)

- The new 120 s bound in `play_complete_game` is asserted **after** the read
  loop, so it catches a slow game but not a hang: if the CLI blocks, the loop
  never ends and the assert is never reached. A real bound needs the child

  release-ignored demo; just don't count it as hang protection.
