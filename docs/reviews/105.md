## Required

1. **The score-unit line is wrong.** The README says:

   > Scores are WTHOR centidiscs: `(black - white) * 100`.

   That is the definition neither the engine nor PLAN.md uses. The code's
   `final_score` gives the **winner the empty squares**
   (`diff + signum(diff) · empties`), a tie with empties scores 0, and every
   search and evaluation score is **side-to-move relative**, not
   black-minus-white. A reader trusting this line would misread every
   `bench` score and every log. Use something like: "Scores are side-to-move
   centidiscs (100 = one disc). Terminal values use the WTHOR rule: the
   winner gets the empty squares, and a tie scores 0, so exact scores span
   ±6400."
